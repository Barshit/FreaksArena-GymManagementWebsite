# 🏋️ Freaks Arena - Gym Management System

A full-stack Gym Management System built using **Node.js, Express.js, MongoDB, EJS, HTML, CSS, and JavaScript**.

The application provides a modern public website for gym visitors along with a secure admin dashboard for gym management.

---

## 🚀 Features

### 🌐 Public Website

- Modern responsive UI
- Membership Plans
- BMI Calculator
- Gallery
- Contact & Membership Inquiry Form
- Announcements Section
- Smooth animations
- Mobile friendly design

---

### 🔐 Admin Dashboard

- Secure Admin Authentication
- Dashboard Overview
- Member Management
- Payment Management
- Membership Renewal
- Membership Pause / Resume
- Announcement Management
- Birthday Notifications
- Membership Expiry Notifications
- Search & Filter Members
- Responsive Admin Panel
